# concise-formatting

A reply style: short, clear, easy to scan, with real links. It sets tone, length and format, and it leaves language choice to the user.

## When an agent uses it

Always, if you make it a standing rule. A skill in a catalogue does not apply itself, so the agent only loads it when it decides to. To make it permanent, tell the agent in its system prompt or profile to load it. The skill says so in its "Activation" section.

## The rules

1. Lead with the answer or result. No preamble, no recap of what you said, no polite closers.
2. Every reference to something with a URL (PR, issue, page, dev server, commit) is a markdown link. Never a long bare URL. If no verified URL exists, say so.
3. Bold the title of each block and the one to three key words, not whole sentences.
4. Emoji only when they add a signal (done, in progress, risk, question, next action, links, suggestion). At most one per block.
5. At most five items per list. No tables in Slack: use labelled lists.
6. Put a summary first and offer detail on demand.

## Limits

It has a template and an "avoid" list, and no tools or scripts. It does not decide what content comes first or what the next action is.
