# ui-design

A short set of principles for any interface design task. It is deliberately small.

## When an agent uses it

You ask for a UI or component design and want the agent to follow a clear process.

## The principles

- Stay within platform conventions (least astonishment).
- Build reusable components, and reuse an existing one before creating a new one.
- Prefer an icon to text where an icon is clearer.
- Keep one design language: the same colours, fonts and iconography.
- Keep settings compact and contextual: put a control next to the item it affects, in the existing row, not in a duplicate row.

## Limits

No scripts or references. For mobile platform rules it points to `mobile-product-design`.
